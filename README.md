# 자금팀 허브 · 개발 문서 (공개판)

장금상선 자금팀 **AI 프로젝트 허브**(팀 과제 현황판)의 기술·운영·인수인계 문서입니다.
MkDocs Material 로 만들고 GitHub Pages 에 자동 배포합니다: https://sinokorofficial.github.io/finance-team-hub-docs/

- 코드 저장소(`SinokorOfficial/finance-team-hub`)는 비공개입니다. 이 문서는 아키텍처·설계·운영 설명용 공개판으로,
  사내망 주소·직원 이름·이메일·실제 과제 내용은 포함하지 않습니다.
- 문서 수정: `docs/` 아래 Markdown 을 고치고 `main` 에 push 하면 `.github/workflows/docs.yml` 이 빌드·배포합니다.
- 로컬 미리보기: `pip install -r requirements.txt` → `mkdocs serve`
