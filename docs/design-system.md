# 디자인 시스템

화면 전체가 CSS 변수(토큰) 몇 벌과 재사용 클래스로 이루어져 있습니다. 색·간격·모서리를 개별 요소에 직접 적지 않고 토큰을 쓰기 때문에, 색을 바꾸려면 `:root` 세 블록만 고치면 됩니다.

## 팔레트 — 스카이블루 한 색

색상은 하늘색 하나로 두고 **위계를 밝기 단계로** 표현합니다. 회색·보라는 쓰지 않습니다(2026-09-08 정리).

| 토큰 | 라이트 | 다크 | 쓰는 곳 |
|---|---|---|---|
| `--bg` | `#EAF3FB` | `#0A1A2B` | 페이지 바닥 |
| `--surface` | `#FFFFFF` | `#10233A` | 카드·목록 행·모달·입력칸 |
| `--surface2` | `#DCEBF8` | `#163049` | 한 단계 들어간 면(안내 줄, 표 머리, 첨부 박스) |
| `--ink` | `#0F2D4A` | `#E3F0FB` | 본문 글자 |
| `--muted` | `#3E6C93` | `#8FBBDF` | 보조 글자·라벨 |
| `--line` | `#BFD8EE` | `#22405E` | 테두리·구분선 |
| `--accent` | `#1B8AE0` | `#4FB0F5` | 주 버튼 바탕·포커스 테두리 |
| `--accent-ink` | `#0F6BB5` | `#8FD0FF` | 링크·강조 글자·숫자 |
| `--accent-soft` | `#D7EAFA` | `#143A5C` | 선택된 버튼 바탕·배지 바탕 |

## 상태 색

상태 하나에 토큰 세 개가 붙습니다 — 배지 바탕(`-bg`), 배지 글자(`-fg`), 목록·카드의 세로 막대(`--bar-…`).

| 상태 | 배지 바탕 | 배지 글자 | 막대 |
|---|---|---|---|
| 운영중 | `--st-run-bg` `#DDF3E6` | `--st-run-fg` `#1B6E43` | `--bar-run` `#22B46A` |
| 개발중 | `--st-dev-bg` `#D7EAFA` | `--st-dev-fg` `#0F6BB5` | `--bar-dev` `#3AA6F0` |
| 구상 | `--st-idea-bg` `#FFF0D2` | `--st-idea-fg` `#8A5A00` | `--bar-idea` `#F2B84B` |
| 중단 | `--st-stop-bg` `#FBE3E3` | `--st-stop-fg` `#A8302F` | `--bar-stop` `#E5484D` |
| 시범운영(폐지) | `--st-pilot-bg` `#D9F2F0` | `--st-pilot-fg` `#0E6F6A` | `--bar-pilot` `#2BB3A9` |

!!! note "시범운영 토큰은 남겨 두었습니다"
    상태 구분 '시범운영'은 2026-09-07 에 '개발중'으로 통합됐지만, 색 토큰은 지우지 않고 **승인 대기 배지·탭 배지의 청록색**으로 계속 씁니다. 옛 자료에 남은 값도 화면에서 깨지지 않습니다.

일정 유형 색은 따로입니다: `--ev-due`(만기) `#B26A00` · `--ev-report`(마감·제출) `#1B8AE0` · `--ev-pay`(상환·지급) `#A8302F` · `--ev-meet`(회의) `#0E6F6A` · `--ev-etc`(기타) `#3E6C93`.

## 다크 모드 — 블록 두 개 규칙

같은 토큰 묶음을 **세 곳**에 씁니다. 순서와 조건이 규칙입니다.

```css
:root{ /* 라이트 팔레트 전체 — 모든 토큰의 기본값은 반드시 여기 */ }

@media (prefers-color-scheme: dark){
  :root:not([data-theme="light"]){ /* 시스템이 다크일 때 */ }
}

:root[data-theme="dark"]{ /* 사용자가 다크를 고른 경우 — 시스템 설정보다 우선 */ }
```

- 어떤 색도 미디어 쿼리 안에서만 정의하지 않습니다. 기본값은 항상 바깥 `:root` 에 있어야 합니다.
- `:not([data-theme="light"])` 가 있어야 "시스템은 다크인데 사용자가 라이트를 고른" 경우가 제대로 뒤집힙니다.
- 다크 블록 두 개는 **같은 내용**입니다. 토큰을 추가하면 두 곳에 같이 넣어야 합니다.

!!! warning "토큰을 안 쓴 색이 조금 있습니다"
    등급 배지(`.tier.t-대` `#FEE2E2`/`#B91C1C`, `.tier.t-중` `#FEF3C7`/`#B45309`)와 '보완필요' 배지(`.pill.need`)는 색을 직접 적어 두었습니다. 그룹 대시보드의 등급 색과 눈으로 맞춘 값이라 그대로 두었는데, 다크 모드에서 밝은 바탕으로 남습니다. 색을 손볼 때 여기부터 보세요.

## 글꼴 · 치수

```css
body{ font-family:"IBM Plex Sans KR","Malgun Gothic","Apple SD Gothic Neo",sans-serif;
      font-size:15px; line-height:1.55; }
```

숫자를 세로로 맞춰야 하는 곳(통계 숫자, 카드 건수, 날짜, 절감 값)은 `IBM Plex Mono` + `font-variant-numeric: tabular-nums` 를 씁니다.

| 요소 | 값 |
|---|---|
| 본문 폭 | `max-width: 1280px` (`.wrap`, 상단 바 내부, 바닥글) |
| 입력칸 | 글자 14px · 패딩 `8px 10px` · 모서리 8px |
| 버튼 `.btn` | 글자 13.5px/600 · 패딩 `8px 13px` · 모서리 8px |
| 목록 행 `.prow` | 패딩 `12px 16px` · 모서리 10px |
| 카드 `.card` `.acard` | 패딩 `16px 18px` · 모서리 12px |
| 모달 | 모서리 14px · `max-width 760px` (`.modal.wide` 1040px) · `max-height 94vh` |
| 배지·알약 | 모서리 999px |
| 효과 지표 입력 | 높이 38px 고정(선택 상자·입력칸 줄 맞춤) |
| 포커스 | `outline: 2px solid var(--accent)` — 모든 조작 요소에 |

### 목록 행 그리드

```css
.prow, .phead{
  display:grid;
  grid-template-columns: 82px minmax(0,1.35fr) minmax(0,1fr) 108px 72px 72px 120px;
  gap:12px; align-items:center;
}
```

순서는 상태 · 과제명 · 메타(업무 영역·서버·범위·주기) · 월 절감 · 링크 · 담당자 · 그룹 대시보드입니다. 머리글이 같은 그리드를 쓰기 때문에 열이 어긋나지 않습니다. 긴 값이 격자를 밀지 않도록 `minmax(0, …)` 와 `min-width:0` 을 함께 씁니다.

### 조회 전용 감추기

```css
body[data-role="viewer"] .needs-edit{ display:none !important; }
```

`applyRole()` 이 `body` 에 역할을 심고, 등록·수정 버튼에는 `needs-edit` 클래스를 붙여 둡니다. 조회 전용 계정에서는 CSS 한 줄로 사라집니다(실제 차단은 서버 — [RBAC](rbac.md)).

## 반응형

기준점은 **820px** 하나입니다.

| 820px 아래에서 | 결과 |
|---|---|
| `.cal-layout` | 2열 → 1열 |
| `.fgrid` | 폼 2열 → 1열 |
| `.prow` · `.phead` | 7열 → `74px minmax(0,1fr) 64px` 3열 |
| 메타·월 절감·담당자·그룹 열 | 감춤 |
| `.savrow` | 3열 → 1열 |
| `.stat.total` | 오른쪽 밀기 해제 |

보조 기준점 두 개가 더 있습니다 — 600px 아래에서 메인 카드 격자가 1열이 되고(기본은 `minmax(520px, 1fr)` 자동 채움), 640px 아래에서 계정 줄이 1열이 됩니다.

## 변화 내성 원칙

1. **상태·영역 이름을 클래스로 씁니다.** `.pill.운영중` 처럼 데이터 값이 곧 클래스라서, 상태를 추가하면 CSS에 한 줄만 더하면 됩니다. 없는 상태는 기본색(구상 계열)으로 떨어집니다.
2. **색은 토큰으로만.** 새 요소를 만들 때 `#` 색을 직접 적지 않습니다. 마땅한 토큰이 없으면 토큰을 먼저 만듭니다.
3. **다크는 세 블록 동시에.** 토큰 추가·변경은 `:root` + 다크 두 블록을 함께 고칩니다.
4. **넓은 내용은 자기 안에서 스크롤.** 표·미리보기는 `overflow:auto` 감싸개(`.upwrap`)에 넣어 페이지가 좌우로 밀리지 않게 합니다.
5. **모션은 최소.** 전환은 토스트·바로가기 아이콘 정도이고, `prefers-reduced-motion` 을 존중합니다.
