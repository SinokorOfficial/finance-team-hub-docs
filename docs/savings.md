# 효과 지표 (그룹 AX 동일 기준)

과제마다 "이 프로그램으로 한 달에 얼마를 아꼈나"를 적는 칸입니다. 선택지·계산식·등급을 **그룹 AX 대시보드 입력 화면과 똑같이** 맞춰 두었고, 그것이 맞는지 독립 검증기로 매번 확인합니다.

## 왜 똑같이 맞추나

허브에 적은 과제는 [엑셀 내보내기](excel.md)로 그룹 AX 대시보드에 그대로 올라갑니다. 허브에서 쓰는 선택지가 대시보드 목록과 다르면 옮길 때 값을 버려야 하고, 계산식이 다르면 같은 과제의 절감 시간이 두 화면에서 달라집니다. 그래서 목록·공식·등급을 대시보드 쪽에 맞추기로 결정했습니다([ADR-0008](adr/0008-savings-parity-with-group-ax.md)).

## 입력 항목 (7칸 + 오류 절감)

| 묶음 | 칸 | 필드 | 선택지·형식 |
|---|---|---|---|
| 시간 절감 | 빈도 | `timeFreq` | `FREQS` 7종 |
| | 주기 | `timeCycle` | `TIME_CYCLES` 6종 |
| | 절감 시간 | `timeValue` + `timeUnit` | 숫자 + 분/시간 |
| 비용 절감(인건비 제외) | 빈도 | `costFreq` | `FREQS` 7종 |
| | 주기 | `costCycle` | `COST_CYCLES` 6종 |
| | 금액 | `costAmount` | 원 단위 숫자 |
| | 근거 | `costBasis` | 자유 입력 |
| 오류 절감 | 있음/없음 | `errSave` | 있음 / 없음 |

!!! note "비용 절감에 인건비를 넣지 않습니다"
    사람의 시간은 '시간 절감'이 담당합니다. 같은 효과를 두 번 세지 않도록 비용 절감에는 구독료·용역비·수수료·지연 페널티처럼 인건비가 아닌 지출만 적습니다(화면의 ⓘ 도움말과 같은 문구).

### 빈도 7종과 배수

`FREQ_MULT` — 한 달에 몇 번 하는 일인지로 환산한 값입니다.

| 빈도 | 배수 |
|---|---|
| 매일 | 20 |
| 주 2~3회 | 10 |
| 주 1회 | 4 |
| 월 2~3회 | 2.5 |
| 월 1회 | 1 |
| 분기 1회 | 0.33 |
| 연 1회 | 0.083 |

### 주기 6종과 배수

시간 절감은 `회당`, 비용 절감은 `건당` 으로 시작하고 나머지 5종은 같습니다. `CYCLE_MULT` 는 회당·건당을 빼고 정의돼 있습니다.

| 주기 | 배수 |
|---|---|
| 회당 / 건당 | (빈도 배수를 씀) |
| 매 근무일 | 20 |
| 주당 | 4.3 |
| 월간 | 1 |
| 분기당 | 1/3 |
| 연간 | 1/12 |

!!! warning "빈도는 주기가 '회당(건당)'일 때만 씁니다"
    주기가 '월간'이면 적은 값 자체가 이미 한 달치이므로 빈도를 곱하면 이중 계산이 됩니다. 그래서 배수 함수가 그때만 빈도를 보고, 편집 폼에서도 주기가 회당/건당이 아니면 빈도 선택 상자를 **비활성**으로 잠급니다(`updateSavingPreview`).

## 계산식

배수 하나로 두 계산을 함께 씁니다.

```js
const savMult = (cycle, freq, per) =>
  cycle === per ? (FREQ_MULT[freq] || 0) : (CYCLE_MULT[cycle] || 0);
```

| 값 | 식 | 반올림 |
|---|---|---|
| 월 절감 시간 (`monthlyHours`) | `(단위가 '분'이면 값÷60, 아니면 값) × savMult(timeCycle, timeFreq, "회당")` | 소수 첫째 자리(0.1) |
| 월 절감액 (`monthlyCost`) | `금액 × savMult(costCycle, costFreq, "건당")` | 1원 |
| 연 절감액 | `월 절감액 × 12` | 1원 |

값이 0 이하이거나 주기가 비어 있으면 0으로 봅니다. 계산 결과가 유한한 수가 아니면 0을 돌려줍니다.

예: 매일 하는 일을 한 번에 30분 줄였다 → 빈도 `매일`, 주기 `회당`, 값 `30` 분 → `30 ÷ 60 × 20 = 월 10시간`.

## 등급 (`tierOf`)

| 등급 | 기준 | 표시 |
|---|---|---|
| 대 | 월 50시간 이상 | 🔴 |
| 중 | 월 10시간 이상 | 🟡 |
| 소 | 월 10시간 미만 | ⚪ |

그룹 초기 운영 기준을 그대로 씁니다. 등급은 **시간**만 보고 매깁니다(비용은 등급에 들어가지 않습니다).

## 필수 규칙

시간 절감 **또는** 비용 절감 중 한 세트는 반드시 채워야 저장(승인 요청)됩니다.

```js
const timeOk  = d => monthlyHours(d) > 0 || (값>0 && 주기 있음 && (주기!=="회당" || 빈도 있음));
const costOk  = d => monthlyCost(d)  > 0 || (금액>0 && 주기 있음 && (주기!=="건당" || 빈도 있음));
const savingOk = d => timeOk(d) || costOk(d);
```

이 규칙은 그룹 대시보드의 '완료' 조건과 같습니다. 승인된 과제인데 `savingOk` 가 거짓이면 목록에 **보완필요** 배지가 붙습니다(`needFill`) — 대시보드의 같은 표시와 같은 뜻입니다. 다 못 채웠으면 초안 또는 임시저장으로 남겨 둘 수 있습니다([기능 카탈로그](features.md)).

## 화면에 어떻게 보이나

| 자리 | 무엇 |
|---|---|
| 편집 폼 `.savblk` | 7칸 + 오류 절감. 값을 고치는 즉시 아래 `.savcalc` 두 줄이 "월 약 n시간 · 등급", "월 약 n원 · 연 n원" 으로 다시 계산됩니다 |
| 목록 '월 절감' 열 | 월 절감 시간 + 등급 배지, 아랫줄에 월 절감액. 둘 다 없으면 `—` |
| 상단 합계 카드 `.stat.total` | 지금 보이는 목록의 월 절감 시간·금액 합계와 "효과 기입 n건 / 전체 m건" |

합계 카드는 **필터 범위와 연동**됩니다. 상태 버튼(운영중·개발중·구상·중단·★·승인 대기)·업무 영역·담당자·검색을 바꾸면 그 범위만 다시 더합니다. 지표를 적지 않은 과제는 세지 않고, 승인 전 초안도 빼고 셉니다(`renderSavingTotal` 이 `isApproved` 로 한 번 더 거릅니다).

금액은 `moneyText()` 가 억·만·원으로 끊어 씁니다.

## 독립 검증기 `verify_saving_parity.py`

허브 코드를 믿지 않고, **대시보드 쪽에서 기준을 다시 받아** 대조하는 읽기 전용 스크립트입니다. 아무것도 고치지 않습니다.

```
py verify_saving_parity.py
```

기준은 두 곳에서 받습니다.

1. 그룹 AX 대시보드 로그인 화면이 내려주는 **공개 JS 청크**(로그인 불필요)에서 효과 지표 모듈을 뽑아 냅니다.
2. 대시보드가 배포한 '채우기' 양식(`server/templates/group_fill_template.xlsx`)의 드롭다운 목록.

검증 항목 7종입니다.

| # | 항목 | 하는 일 |
|---|---|---|
| 1 | 선택지 | 대시보드의 빈도·주기·단위 목록과 배수, 등급 기준(50·10) vs 허브 상수 |
| 2 | 공식 | 대시보드 함수와 허브 함수를 node에서 나란히 실행해 **1,512가지 조합**(빈도 7 × 주기 6 × 값 12개 × 시간/분 2 = 1,008 시간 + 504 비용) 비교, 등급 경계값(0·9.9·10·49.9·50·120시간)까지 |
| 3 | 입력칸 | 편집 폼(`savingBlockHtml`)이 그 상수만으로 선택지를 만드는지 — 하드코딩된 목록이 끼어들지 않았는지 |
| 4 | 왕복 | 실제 과제 → 허브 월 환산 값 vs 허브가 만든 그룹 채우기 양식 행을 대시보드 공식으로 계산한 값. 양식에 단위 열이 없으므로 분→시간 환산이 맞는지까지 잡힙니다 |
| 5 | 양식값 | 양식에 쓰인 빈도·주기 문구가 그 양식의 드롭다운 목록에 있는지 |
| 6 | 필수 | 허브 필수 규칙(시간 또는 비용 한 세트)이 대시보드 완료 조건과 같은지 |
| 7 | 배포본 | 사내 서버가 실제로 내려주는 화면에 검증한 계산 코드와 선택지 목록이 그대로 들어 있는지(줄바꿈 차이는 무시) |

!!! tip "언제 돌리나"
    효과 지표 관련 상수·함수·양식을 고쳤을 때, 그리고 그룹 대시보드가 입력 화면을 바꿨다는 얘기가 들릴 때. node와 인터넷 연결이 필요합니다.

## 옛 항목 자동 변환

2026-09-09 이전에는 절감 칸이 `freq` / `saveTime` / `saveUnit` / `saveCost` 4개였습니다. 서버가 뜰 때 `migrate_savings()` 가 옛 키를 가진 문서만 한 번 바꿉니다.

| 옛 필드 | 새 필드 |
|---|---|
| `freq` | `timeFreq` (그룹 목록에 없는 값이면 비움) |
| `saveTime` + `saveUnit` | `timeValue` + `timeUnit`, `timeCycle = "회당"` |
| `saveCost` | `costAmount`, `costCycle = "월간"` |
| `timeHours`(v3.17) | `timeValue` + `timeUnit = "시간"` |

**목록에 없거나 숫자가 아닌 값은 버리지 않고 비고 끝에 `(구)` 로 남깁니다.** 예: 옛 빈도 '수시'는 그룹 목록에 없으므로 `timeFreq` 를 비우고 비고에 `절감 빈도(구): 수시` 를 붙입니다. 담당자가 나중에 가장 가까운 값을 골라 채우면 됩니다.

승인 대기 중인 수정 요청(`req.data`) 안의 값도 같이 변환하고, 변환 건수는 감사 기록(`audit`)에 남깁니다. 이미 변환된 문서는 다시 건드리지 않으므로 서버를 여러 번 띄워도 안전합니다.
