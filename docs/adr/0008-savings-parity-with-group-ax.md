# ADR-0008 · 효과 지표는 그룹 AX 대시보드와 동일 기준

| 항목 | 내용 |
|---|---|
| 상태 | 채택 (2026-09-09, v3.18) |
| 결정 | 효과 지표의 선택지·월 환산 공식·등급 기준을 그룹 AX 대시보드 쪽에서 확인해 **그대로** 채택하고, 독립 검증기로 왕복 대조합니다. |

## 배경

허브에 입력한 ★ 과제는 [그룹 양식] 엑셀로 내보내 그룹 AX 과제 대시보드에 등록됩니다. 즉 허브의 효과 지표 값이 그대로 밖으로 나갑니다.

초기 허브의 절감 항목은 자체 설계였습니다(절감 빈도 / 회당 시간 / 단위 / 월 비용). 반면 대시보드는 시간·비용 절감을 각각 '빈도 · 주기 · 값' 세 칸으로 받아 월 환산 시간을 계산하고 등급(대·중·소)을 붙입니다. 기준이 다르면 담당자가 같은 값을 두 번 입력해야 하고, 옮겨 적는 과정에서 결과가 달라집니다.

## 결정

허브 쪽을 대시보드 기준에 맞춥니다. 기준은 짐작하지 않고 **대시보드 로그인 페이지가 내려주는 공개 스크립트와 대시보드가 배포한 '채우기' 양식의 드롭다운 목록**에서 확인해 그대로 옮겼습니다.

| 구분 | 값 |
|---|---|
| 빈도 (7) | 매일 · 주 2~3회 · 주 1회 · 월 2~3회 · 월 1회 · 분기 1회 · 연 1회 |
| 시간 절감 주기 (6) | 회당 · 매 근무일 · 주당 · 월간 · 분기당 · 연간 |
| 비용 절감 주기 (6) | 건당 · 매 근무일 · 주당 · 월간 · 분기당 · 연간 |
| 시간 단위 (2) | 분 · 시간 |

허브에만 있던 '수시' 는 대시보드 목록에 없어 삭제했습니다.

```js
const FREQ_MULT  = {"매일":20, "주 2~3회":10, "주 1회":4, "월 2~3회":2.5,
                    "월 1회":1, "분기 1회":0.33, "연 1회":0.083};
const CYCLE_MULT = {"매 근무일":20, "주당":4.3, "월간":1, "분기당":1/3, "연간":1/12};
```

주기가 `회당`(비용은 `건당`)이면 빈도 배수를, 그 외 주기는 주기 배수를 씁니다. 단위가 `분` 이면 60 으로 나누고 0.1시간 단위로 반올림합니다. 등급은 월 환산 50시간 이상 '대', 10시간 이상 '중', 그 아래 '소'. 필수 규칙은 시간 절감(절감 시간) 또는 비용 절감(금액) 중 **하나**의 빈도·주기·값 세 칸(대시보드 완료 조건과 같은 기준).

**독립 검증기** — 허브 코드를 믿지 않고 대조하는 별도 프로그램 `verify_saving_parity.py`(읽기 전용, DB 사본만 사용)를 만들었습니다. 검증 항목 일곱 가지는 ① 선택지·배수·등급을 대시보드 공개 스크립트에서 다시 받아 비교 ② 두 쪽 함수를 node 에서 나란히 실행해 **1,512 조합**(빈도 7 × 주기 6 × 단위 2 × 값 여러 개) 전수 비교 ③ 편집 폼이 그 상수만으로 선택지를 만드는지 ④ 과제 데이터의 허브 월 환산 값과 그룹 양식 행을 대시보드 공식으로 계산한 값의 왕복 대조 ⑤ 양식에 쓴 문구가 그 양식의 드롭다운 목록 안에 있는지 ⑥ 필수 규칙이 대시보드 완료 조건과 같은지 ⑦ 사내 서버가 실제로 내려주는 화면에 검증한 코드가 그대로 들어 있는지 입니다.

**옛 데이터 변환** — 서버 기동 시 `migrate_savings()` 가 옛 키를 새 7칸으로 1회 변환합니다. 분은 시간으로 나누고, 목록에 없는 값이나 숫자가 아닌 값은 지우지 않고 비고 끝에 `(구)` 로 남깁니다. 엑셀 업로드는 새·옛 머리글을 둘 다 알아봅니다.

## 결과 (장점 · 감수한 단점)

**장점**

- 한 번 입력하면 그대로 그룹으로 나갑니다. 옮겨 적는 단계와 그 오차가 없어졌습니다.
- 월 환산 시간·등급·금액이 입력 중에 바로 보이고, 목록에 '월 절감' 열과 상단 합계 카드를 붙일 수 있게 됐습니다.
- 기준이 어긋나면 검증기가 잡아냅니다(사람 눈으로 대조하지 않음).

**감수한 단점**

- 허브 기준이 대시보드에 종속됩니다. 그쪽이 배수·등급을 바꾸면 허브도 따라 바꾸고 검증기를 다시 돌려야 합니다.
- 검증기는 대시보드 공개 스크립트를 받아 오므로 인터넷과 node 가 필요합니다.
- 입력 칸이 늘어 담당자 부담이 커졌습니다(대신 필수는 시간·비용 중 한 세트만).

## 되돌릴 때

허브 자체 기준으로 돌아가려면 배수표와 등급 함수를 바꾸면 되지만, 그룹 양식으로 내보낼 때 변환표가 필요해집니다. 그룹 전달을 하는 동안에는 되돌릴 이유가 없습니다. 대시보드가 기준을 바꾸면 이 ADR 의 표와 상수를 함께 갱신하고 검증기를 통과시키는 것이 절차입니다.
