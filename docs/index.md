# 자금팀 허브 · 개발 문서

자금팀 허브는 자금팀의 AI·자동화 과제를 한곳에 모아 놓은 사내 웹 현황판입니다. 누가 어떤 과제를 맡아 어디까지 진행했는지, 그 과제로 매달 얼마나 시간·비용을 줄였는지, 팀의 자금 일정이 언제인지를 한 화면에서 보고 직접 고칠 수 있습니다.

구조는 아주 단순합니다. 브라우저에서 열리는 화면 파일 한 개, 사내 서버 PC에서 돌아가는 작은 파이썬 서버 한 개, 데이터 파일 한 개(SQLite)뿐이고 외부 서비스나 별도 데이터베이스 서버에 의존하지 않습니다. 그래서 폴더를 통째로 복사하면 다른 PC나 클라우드로 그대로 옮길 수 있습니다.

이 문서는 전산팀 인수인계와 유지보수를 위한 공개판입니다. 시스템이 어떤 부품으로 이루어져 있고, 데이터가 어디에 어떤 모양으로 저장되며, 코드를 고쳐서 서버에 반영하는 길이 무엇인지를 설명합니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 현재 버전 | v3.21 (2026-09-09, 사내 서버판) |
| 기술 스택 | 화면은 `hub.html` 한 파일(HTML + CSS + 바닐라 JavaScript, 약 210KB). 외부 라이브러리는 엑셀 읽기용 SheetJS 0.18.5 하나뿐이고 서버에 함께 넣어 두어 인터넷 없이 동작합니다. 서버는 Python 3.12 · FastAPI · uvicorn |
| 호스팅 | 사내 서버 PC에서 Windows 예약 작업으로 상시 실행(포트 8002, 사내망 전용). 접속 주소는 사내 인수인계 문서 참조 |
| 인증 | 자체 계정 로그인. 회사 이메일 도메인 2개만 가입 허용, 비밀번호는 PBKDF2-SHA256 15만 회 해시로만 저장, 세션은 httponly 쿠키 `hub_sid`(7일) |
| 데이터 | SQLite 파일 한 개(`server/hub.db`) — 문서형 단일 표 `docs` 안에 컬렉션 5개. 첨부파일만 `server/uploads/` 폴더에 별도 |
| 역할 | 3종 — 관리자 · 일반 · 조회 전용. 가입 신청은 관리자 승인 후 사용 |
| 실시간 반영 | SSE(`GET /api/stream`) — 누가 저장하면 접속 중인 모든 화면이 스스로 다시 읽어 갱신 |
| 배포 | GitHub Actions → 사내 서버 PC의 self-hosted runner(라벨 `hub`)가 `server/deploy.ps1` 실행 |
| 저장소 | `SinokorOfficial/finance-team-hub` (**비공개** 저장소). 데이터 파일은 저장소에 올리지 않습니다 |
| 향후 | 전산팀 Azure 이관 예정 — 이관 후 접속 주소와 로그인 방식(회사 MS 계정)이 바뀝니다 |

## 무엇을 하는가

- **과제 취합** — 흩어져 있던 팀의 AI·자동화 과제를 한 게시판에 모읍니다. 업무 영역 6종(입출금 · 금융 · 공시 · 외부 제출 · 보고 및 내부 관리 · 기타)으로 나눠 봅니다.
- **분산 입력** — 담당자가 자기 과제를 직접 고칩니다. 중요 과제(★)만 관리자 승인 절차를 거치고, 나머지는 담당자가 바로 저장합니다.
- **효과 측정** — 시간 절감(빈도 · 주기 · 시간)과 비용 절감(빈도 · 주기 · 금액 · 근거)을 입력하면 월 환산 합계를 계산합니다. 선택지와 계산식은 그룹 AX 과제 대시보드와 같은 기준으로 맞춰 두었습니다.
- **일정 관리** — 만기 · 마감·제출 · 상환·지급 · 회의 · 기타 5종의 자금 일정을 월 달력으로 봅니다.
- **엑셀 왕래** — 취합 양식 엑셀을 업로드해 여러 건을 한 번에 등록하고, 팀 현황 엑셀과 그룹 제출용 채우기 양식을 서버가 만들어 내려줍니다.
- **자료 붙이기** — 과제마다 사용안내 요약(글), 매뉴얼 문서 첨부(1건 20MB까지), 링크(URL)를 답니다. 운영중 과제는 요약과 문서가 모두 필수입니다.
- **바로가기** — 업무 영역별로 자주 쓰는 외부 시스템·문서 링크를 화면에서 직접 추가·수정합니다.
- **이력 확인** — 과제가 저장될 때마다 서버가 바뀐 항목만 골라 기록하고, 과제 상세 창에서 최근 30건을 볼 수 있습니다.
